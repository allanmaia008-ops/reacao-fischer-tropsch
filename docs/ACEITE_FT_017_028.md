# Fechamento do intervalo FT-017 a FT-028

## Estado consolidado

| Atividade | Estado | Pendência real |
|---|---|---|
| FT-017 | gate implementado | cortes experimentais compatíveis |
| FT-017A | preparação concluída | dados completos para AIC/BIC e revisão de resíduos |
| FT-018–020 | concluídas | nenhuma pendência estrutural |
| FT-021 | aprovada para uso interno | sem redistribuição pública |
| FT-022–026 | concluídas como portas/infraestrutura | validação externa quando aplicável |
| FT-027 | contrato concluído | execução de piloto real |
| FT-028 | concluída | nenhuma pendência estrutural |

As pendências não foram apagadas por aprovação administrativa: FT-017/017A exigem
bandas comparáveis e FT-027 exige experimento real. Todos os bloqueios permanecem
explícitos para impedir que um resultado parcial seja apresentado como modelo LTFT
validado.

## Critério de encerramento científico

O intervalo FT-017–028 só poderá ser declarado totalmente encerrado quando houver
uma distribuição experimental nos cinco cortes ASF (ou método publicado de
desagregação), incertezas e revisão independente dos resíduos, além de um piloto
com dados brutos rastreáveis.
