# Dados externos para FT-017A

Foi criado `data/evidence/ltft_external_partial_selectivity.csv` com valores publicados encontrados em fontes primárias/institucionais. Cada linha conserva URL, banda, base, estado e observação de extração.

Os dados são **parciais**: não fornecem simultaneamente os cinco cortes `CH4`, `C2-C4`, `C5-C11`, `C12-C20`, `C21+`, e algumas bandas se sobrepõem. Portanto, a plataforma não os usa para ajuste, AIC/BIC ou validação completa sem verificação manual do artigo e harmonização dos cortes.
